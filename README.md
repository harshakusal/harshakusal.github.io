# Harsha Vardhan Ramisetty · Portfolio

Static site with no build step: `index.html`, `styles.css`, `script.js`, `assets/`.

- Open `index.html` directly in a browser, or serve it with `python3 -m http.server 8000`.
- GitHub Pages: push these files to a repo (for example `harshakusal.github.io`) and enable Pages from the root of the main branch.
- Hero video: drop a looping MP4 at `assets/hero.mp4`. Until then the photo `assets/photo_full.jpg` is shown, and if that is missing too, an "HV" monogram appears. See `AVATAR_GUIDE.md`.
- ID card photo: `assets/photo.jpg`. If it is missing, initials are shown instead.
- Resume: `assets/Harsha_Vardhan_Ramisetty_Resume.pdf`.
